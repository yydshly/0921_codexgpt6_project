# 月下造境 · 互动短篇

网站默认首页为项目总览 `/#overview`；`/#story` 进入全景互动短篇《给团圆留一盏灯》：推开窗，让月光照到旧照片，再把旧时与今天放在一起。体验者的点击、划动和拖放推动故事；创作者可以替换图片、文字和每一段声音，重新编排触发条件与回应。

`/#picture` 保留上一版互动图片实验，`/#letters` 保留月光来信；`/#sea`、`/#paper`、`/#sound` 是早期灵感画布。**本节说明当前 story 版本；文末旧章节按历史保留，其中的默认入口、文件格式、音频保存方式和容量限制不适用于 story。**

## 先体验，再改成自己的故事

在顶部“体验另一份故事”中选择样片。两份样片共用同一套图层、规则和播放器：

| 样片 | 体验中的动作 |
| --- | --- |
| 给团圆留一盏灯 | 划开木窗 → 将月光拖到旧照片 → 把旧照片拖向今天的家。 |
| 桂下藏诗 | 轻触诗笺 → 划过古诗 → 将月亮拖到下句留白。初始作品标题为“给月亮留半句诗”。 |

画面下方的“轻点也能继续”可触发当前可用的一段互动，“从头体验故事”会重置播放状态。样片家庭照片和回忆均为明确标示的虚构创作素材；不会伪造亲人回应，也不会自动向他人发送消息。

点“编排故事”进入编辑。可在画面中选中和拖动物件，也可用数值修改位置、宽高、角度、透明度、前后层次和开场是否显示；可替换图片、修改文字、作品开场及结尾。图片可选择完整显示或铺满区域。

## 图层与动作编排

作品模型支持图片（`image`）、文字（`text`）和触发区域（`zone`）。编辑面板可新增图片、文字并编辑已有图层；自定义触发区域也可通过作品 JSON 定义。

每条规则指定触碰的图层，以及点击（`click`）、划动（`swipe`）或拖到另一图层（`drop`）的触发方式。`requires` 指定必须先完成的规则，供故事逐段展开；当前规则在一次体验中只触发一次。面板提供单个前置规则选择，JSON 模型可表达多个前置规则，并检查循环依赖。

一条规则可组合多种回应：

| 动作 | 实际效果 |
| --- | --- |
| `show` / `hide` | 显示或隐藏指定图层。 |
| `move` | 将图层移到指定位置。 |
| `text` | 改写指定文字图层。 |
| `audio` | 播放指定音频，可设置音量与循环。每个回应可配置独立文件，也可复用已有声音。 |
| `stopAudio` | 停止声音；JSON 可指定音频，未指定时停止全部音频。 |
| `narrate` | 使用接收设备的系统声音朗读指定文字。 |
| `finish` | 展开作品结尾。 |

每个回应可设置延时。延时是**相对本条规则被触发的时刻**计算，不是依次累加，也不会自动等待上一段音频播放完。面板使用秒填写，JSON 中的 `delay` 使用毫秒。

声音文件与系统朗读是两种来源：上传的配音、音乐可随作品完整保存和导出；系统朗读依赖接收者设备的中文声音与浏览器支持，不会生成或打包合成语音文件。默认示例配乐为原创程序合成音乐。

## 完整保存、继续改编与独立播放

- **保存**：将当前作品和全部所需图片、音频、图层及规则写入当前浏览器、当前站点地址的 IndexedDB。当前只保存一份作品快照，再次保存会更新它；没有账号或云同步。保存的是创作内容，不是体验者当前的播放进度。
- **可以接着改编的作品**：下载 `.moonstory.json`，媒体以内嵌数据保留。在本应用“打开作品”后可恢复内容并继续编排。该格式与旧 `.picture.json`、`.moonletter.json`、`.moon.json` 不互通。
- **可播放的独立网页**：下载单个 `.html`，其中内嵌作品媒体、样式和与应用相同的通用播放器。在支持网页脚本的浏览器中打开即可体验，媒体与播放器不依赖本应用服务器或 CDN，也不要求接收者安装编辑器；系统朗读仍依赖设备提供的声音。
- **先看独立播放效果**：在应用内 iframe 中运行实际打包的独立 HTML，使用与导出文件相同的播放器。

编辑修改时会清理不再被图层或规则引用的素材，避免已经替换掉的图片、声音仍留在作品包中。导出不会更新本地保存的快照；切换样片暂存的另一份草稿仅在当前页面会话中保留。

应用采用 GitHub Pages 部署，实际地址与最新发布状态见根目录 README。个人创作仍保存在本机，独立 HTML 下载不会自动公开你的内容或生成分享链接。

## 本轮验证与可直接交付的样片

48项自动检查通过，桌面与手机尺寸下实际完成交互、编辑、保存刷新恢复、导入及独立播放。详情见 `design-qa.md`。两份已打包的样片位于 `public/story-examples/reunion.html` 与 `poetry.html`；同目录的 `.moonstory.json` 可导入编辑。运行 `node scripts/create-story-examples.mjs` 可使用当前播放器重新生成。

## story 的文件边界

完整 JSON 作品上限为 **40 MB**，包含媒体编码后的数据；单张内嵌图片上限 **8 MB**，单段音频上限 **12 MB**。图片上传支持 JPG、PNG、WebP，原文件不超过 20 MB；浏览器将最长边缩至不超过 **2048 px**、小图不放大，并生成 WebP 副本，最终仍须满足作品图片与总文件上限。原文件不变。

音频支持浏览器可解码的常见 MP3、WAV、OGG、M4A 等格式，实际播放取决于浏览器支持。作品导入会校验版本、图层和素材引用、触发方式、动作、前置条件与文件大小；只接受支持的预设素材或内嵌图片、音频，不接受任意外链素材或可执行脚本。

当前实现入口为 `src/StoryApp.jsx`（体验与编辑）、`src/storyModel.js`（模型、校验和完整保存）、`src/storyPlayer.js`（通用播放器）、`src/storyExport.js`（单 HTML 导出）及 `src/ExperienceRoot.jsx`（入口切换）。以下历史章节中的测试命令与验收描述对应各自旧流程，不能作为 story 已完成验证的声明。

# 月下造境 · 互动图片（保留的旧实验说明）

当前默认首页和 `/#picture` 都进入互动图片体验：在一张月夜图中拖动月亮、唤出古诗、亲手画一条航线，让纸船载着一句话抵达。先体验图片里的回应，再把它改成自己的作品。旧来信实验保留在 `/#letters`，三种灵感画布仍可从 `/#sea`、`/#paper`、`/#sound` 进入。

## 新版先这样体验

1. **借一束月光**：拖动月亮，海面的倒影随之移动。月亮获得键盘焦点后，也可用方向键调整位置。
2. **唤醒一句诗**：点水面互动点，或轻触画面下半部，触发涟漪并展开文字。默认是张九龄“海上生明月，天涯共此时”。
3. **送一句心意**：点纸船，修改它要带走的话；选择“亲手画一条路”，在水面按住拖动，松手后纸船沿航线前进，抵达后展开寄语。也可选择“沿月光航行”，使用预设路线。**这是图中的动画旅程，不会向任何人发送消息。**

月光倒影和水面折射是内置月夜场景的效果；更换为自己的图片后，使用上传图片与可放置的互动点，不会自动识别或重建照片中的水面。

## 编辑图片、字句与互动点

点“编辑这张图”打开编辑面板，可以修改标题、点的名字和文字，添加“展开诗句 / 展开一句话 / 播放声音 / 泛起涟漪”等预设动作。月亮、水面、纸船保留各自的内置动作，名字、位置和文字可改；自定义点可删除。一张图最多 15 个点，每个点的文字最多 500 字。

编辑时可直接拖动点；手机也可以点“在图上重新放置”，收起面板后在目标位置点一下。添加互动点同样是在画面中选择位置。声音动作使用当前统一音源，没有为每个点分别配置音轨。

图片支持 20 MB 以内的 JPG、PNG、WebP。在浏览器中将最长边缩至不超过 **1600 px**，小图不放大，再尝试压缩后加入作品。保存的是处理后的图片副本，原文件不变；压缩后仍过大的图片会提示重新选择。

## 配乐、配音与系统朗读

- 顶部配乐按钮控制播放；编辑面板可以开关背景配乐、选择自己的配音或配乐文件。支持浏览器能解码的常见 MP3、WAV、OGG、MP4/M4A、WebM 音频，单个文件不超过 20 MB；实际接受结果还取决于文件的音频 MIME 类型。
- 默认仍是约 51 秒的原创程序合成示例配乐。**自选音频仅用于本次页面会话，不随保存或导出保留。** 刷新、重新打开或导入作品后，需要重新选择声音文件；只有音频名称与配乐开关会保存在作品设置中，未重新载入自选文件时使用示例配乐并在页面注明。
- 文字展开后可点“系统朗读”，调用浏览器和系统提供的中文声音；没有可用中文声音时会提示改用自己的配音。它不使用本项目训练的配音模型，音色与可用性取决于设备，也不会生成可下载的语音文件。新版图片页面没有录音功能，已有麦克风录音仍在旧“声音成诗”中。

## 新版保存与 JSON 文件边界

“保存作品”把当前一份图片作品写入**同一浏览器、同一站点地址的本地存储**；再次保存会更新这份快照。它不是云同步，也不是多作品收藏库。未点保存的修改、手绘航线、航行进度、已触发的动作和播放状态不会恢复。

“导出”可以下载 `月下造境.picture.json` 或复制 JSON 内容，保存标题、图片、互动点及其位置、文字、动作和配乐设置。自选图片以压缩后的图片数据内嵌，内置图片保存素材引用。另一台设备需运行本应用并导入文件才能继续体验、编辑；JSON 本身不是独立网页、视频、图片成品或公开链接。

**文件不包含自选音频、系统朗读声音或手绘航线。** `.picture.json` 与旧 `.moonletter.json`、`.moon.json` 不互通。页面导入文件限 2,300,000 字节，并校验版本、图片格式、点数量、坐标、动作与文字边界；错误文件会给出提示。应用不会自动向他人发送文件，也没有任意 AI 效果编程、图片内容识别或自动生成配乐功能。

新增实现入口是 `PictureApp.jsx`、`PictureEditor.jsx` 和 `pictureModel.js`。模型测试可运行 `node --test tests/pictureModel.test.mjs`，覆盖数据校验、本地保存、JSON 往返和航线插值；它不代替手机手势、系统中文朗读、音频解码和真实画面效果检查。

# 月下造境 · 月光来信（保留的旧实验说明）

中秋双人共创的本地网页原型：写信人留下一段记忆和原创上半句，收信人读信、续写下一句并回信，最后得到保留两个人城市与署名的月光作品。

默认进入新的“月光来信”；原来的三种可编辑场景保留在“灵感画布”。当前没有账号、云端信箱、公开分享链接或自动发送。页面中的“封好这封信”表示邀请内容已准备，**不表示已向任何人送达**。

## 月光来信的实际流程

1. **写给谁**：填写自己的落款、所在城市和收信人的名字，选择古诗引子。三首可选诗分别是张九龄《望月怀远》、苏轼《水调歌头》和李白《月下独酌》，页面保留作者、解释与资料链接。
2. **留下你的故事**：写一段记忆和自己的上半句，给信起名。记忆最多 600 字，上半句最多 80 字。古诗是引子，用户原创句子单独呈现与署名。
3. **决定怎样开信**：选择接一句古诗、回答一个默契问题或直接打开，再选择作品风格。问题是开信的仪式，没有需要验证的“正确答案”，也不是密码。
4. **封好并准备邀请**：完整内容保存在“我的信箱”，状态变为等待回应。可以切换到收信人视角在本机体验，也可以复制或下载邀请，手动交给另一个人。
5. **读信与续写**：收信人完成所选开场后阅读原信，填写自己的落款、城市、原创下句和回信。下句最多 80 字，回信最多 600 字，四项均需填写。默契问题的回答会预填到回信开头，可以继续编辑。
6. **共同完成**：两句原创文字、两个城市和两人署名进入作品，完整信保存到收信人当前浏览器。结果页可切换“只有我的上半句 / 两个人完成之后”，查看作品变化，也可重新阅读原信。
7. **把回信交还写信人**：导出回信，由写信人在保存了原信的浏览器导入，合成自己的完整收藏。

“先体验一封来信”使用明确标注的示例人物与故事；续写仍由体验者实际填写，不会自动伪造对方回应。已有回信不能被另一份回应覆盖。“沿用这个玩法，再写一封”会创建新草稿，保留诗词、上半句、开信方式、问题与视觉风格，清空双方身份、私人故事及回信，供重新填写。

## 三种作品风格

| 月光来信风格 | 成品表达 | 对应灵感画布 |
| --- | --- | --- |
| 月光海面 | 深蓝夜海、远山和月光，呈现从上半句到两人共同署名的变化。 | 月光造境，`/#sea` |
| 山水诗笺 | 象牙色纸张、桂花与浅墨山水，深色正文，保留两个人的原句。 | 诗笺工坊，`/#paper` |
| 水岸回响 | 月夜水池与暖白反射，呈现两句原创回应；非紧凑成品可播放明确标注的“示例配乐”。 | 声音成诗，`/#sound` |

来信成品是阅读与共创结果展示，月亮和文字不在这个流程中拖动。文字保持为可选择的真实网页文字，没有烘焙进背景图。水岸回响中的配乐不是用户录音，也不会朗读信中文字；自己的音频导入与录音功能仍位于“灵感画布 → 声音成诗”。

## 邀请与回信怎样往返

导出窗口支持**复制完整 JSON 内容**和**下载 `.moonletter.json` 文件**。剪贴板不可用时，可以展开“查看完整内容，也可手动复制”。本应用不会代为发送微信、邮件或其他消息。

| 文件 | 内容与导入结果 |
| --- | --- |
| 邀请：`kind: moon-letter-invitation`、`version: 1` | 包含写信人的题目、名字、城市、收信人名字、故事、上半句、诗词、开信设置、风格与配对编号；不包含回信。收信人导入后进入开信流程。 |
| 回信：`kind: moon-letter-reply`、`version: 1` | 包含回应者的名字、城市、下一句、回信内容，以及对应原信编号；不重复包含原信故事。导入后与本地对应原信合并。 |

跨设备往返：

1. 写信人在“邀请已准备”页点“准备邀请内容”，复制内容或下载文件，通过自己选择的渠道交给对方。
2. 对方在能够运行本应用的设备上，点“我有一封来信”，粘贴完整内容或“选择文件”，然后读信、续写。
3. 对方在结果页点“把回信交还给写信人”，复制或下载回信，手动交还。
4. 写信人回到**保存原信的同一浏览器与站点地址**，点“我有一封来信”导入回信。原信与回信编号匹配后，信箱中的记录变为共同完成。

邀请和回信文件均限 **64 KB**。文件是明文 JSON，包含信中文字，不含音频、图像副本或线上访问令牌。导入会检查格式、版本、字段、字数、状态和编号；错误文件不会完成合并。重复导入完全相同的已收录回信会打开原收藏，不会另建一封；另一份不同回应不能覆盖已有回信。

回信必须匹配当前浏览器中已保存的原信。**单独一份回信文件无法恢复整封作品**；当前来信流程也没有把完整收藏导出为图片、视频、公开链接或通用整库备份的功能。另一台设备必须能运行本应用，收到 JSON 本身不会自动打开一个在线作品页。

## 保存在哪里

- “我的信箱”保存草稿、等待回应及共同完成的来信，使用当前站点的 `localStorage`；应用对来信库设置约 4 MB 的大小上限，浏览器本身也可能施加限制。
- 当前写信步骤、视角和未提交的回复会写入 `sessionStorage`，以便同一标签页刷新后继续；它不等于已收藏的信箱记录。需要留下草稿时使用“保存草稿”；进入下一步和封信时也会保存。
- 邀请导入后先进入阅读流程，不会仅因打开文件就新增完整收藏；完成回应时才保存这封共同作品。
- 旧灵感画布的“我的作品”使用独立的 IndexedDB 作品库，与新信箱不是同一套数据。

保存只发生在当前设备、浏览器与站点地址中。清理网站数据、切换浏览器或改变访问地址后，不会自动同步过去的内容。当前没有服务器收件、消息通知、远端身份核验或多端实时协作。

## 保留的灵感画布

从顶部“灵感画布”进入，或直接访问 `/#sea`、`/#paper`、`/#sound`。画布中的“月光来信”可返回新流程，地址为 `/#letters`；无哈希的首页也进入来信流程。

旧画布仍支持：

- **月光造境**：拖动月亮和诗句，调整月光亮度、大小与动作；点击月亮或画面显示寄语、切换诗句或触发涟漪。支持方向键移动。
- **诗笺工坊**：在纸纹、山水与桂花之间编排诗句，调整字间留白，设置月亮或桂花触发的回应。
- **声音成诗**：播放示例配乐、导入自己的本地音频，或主动授权麦克风录一段声音。真实音量与频谱驱动画面，可调回应强度；暂停时不会生成假频谱。

旧画布可命名、撤销、体验、保存和“以此继续创作”。“导出作品”生成 `.moon.json`，保留可编辑设置，并在使用自有音频时包含音频数据；“导入作品”恢复为新作品。此格式与新来信的 `.moonletter.json` 不互通。

单个音频限 20 MB，旧画布作品文件限 30 MB；录音最长 60 秒，须主动点击并获得麦克风权限，适用于 HTTPS 或本机预览。音频在浏览器内处理，不调用外部语音生成或上传接口。实际解码与播放能力取决于浏览器；录音时不向扬声器回放麦克风。

这些是预设场景和已实现交互，当前没有任意提示词生成新效果、文字转语音、AI 唱歌、自动作曲或视频导出的产品接口。

## 视觉、声音与实现来源

场景背景和透明月亮由本次对话的内置 Image Gen 制作，运行时素材位于 `public/assets`。海面、水池和纸笺使用真实栅格素材；文字、月亮对象及交互由应用单独呈现。水面折射和月光反射使用 Three.js 着色器，WebGL 不可用时回退到对应原图。

`demo-music.mp3` 是本项目先前制作的约 51 秒原创程序合成配乐，不是用户原声或信件朗读。字体为 Noto Serif SC / Noto Sans SC 的界面子集与系统后备字体，Noto 采用 SIL Open Font License；图标使用 `@phosphor-icons/react`。逐项素材来源见 [视觉与声音素材记录](design/asset-provenance.md)。

主要维护入口：`LetterApp.jsx` 组织来信流程，`letterStore.js` 管理校验、存储与文件往返，`LetterArtifact.jsx` 展示双人作品，`letterContent.js` 保存古诗、开场与风格资料，`ExperienceRoot.jsx` 连接新流程与旧画布。原有 `useStudioAudio` 继续自行管理音源、录音和资源清理；父组件无需重复设置音频 `src`。

# 《这一家》｜一桌人，终于坐下

中秋纸艺插画样片。以虚构家庭小事表现“团圆、家、和气”，用于评估产品的视觉、声音和叙事方向。

## 成品

- `output/这一家-中秋样片.mp4`：1920×1080，24 fps，约51秒，H.264＋AAC，含字幕、合成旁白和原创程序合成氛围配乐。
- `output/分享封面.png`：竖版分享海报。
- `output/cover-landscape.jpg`：横版片头封面。
- `output/captions.srt`：对应最终影片的字幕。
- `output/contact-sheet.jpg`：关键帧总览。

人物、情节、对白均为虚构创作示范，不代表真实家庭经历或家庭原声。作品采用AI生成纸艺插画、可控镜头推进和淡切，不是人物连续动作的生成式视频。

## 创作方向

固定靛蓝衣父亲、赭红衣母亲、姜黄衣孩子；同一木桌、圆窗、月光、陶瓷与纸面纹理贯穿镜头。

故事：爸爸说少买一点，却多提回一袋水果；孩子挑双黄月饼；厨房和门口互相招呼；忙了好几回，一家人终于坐下。最后水果与分好的月饼呼应开场。

首版没有加入真实品牌名称、商品、二维码或投放链接。正式品牌片应在用户提供品牌后配置，并根据渠道另行安排竖版视频构图。

## 制作与来源

- 六张电影插画与竖版封面均由本任务内置图像生成工具生成。源图保存在 `assets`，原图未覆盖修改。
- 片头、片尾和字幕采用独立字体排版。片中使用 Noto Serif SC、Noto Sans SC，系统内现有字体。
- 旁白：MiniMax `speech-2.8-hd`，`female-shaonv`，语速0.89；原始音频43.704秒，原始11句时间戳保存在 `assets/audio/provider-subtitles.json`。
- 配乐：`src/make_music.py` 生成的原创稀疏毡音、和弦和空气层，无第三方音乐下载或采样。
- 镜头：按句级时间戳编排；旁白统一延后4秒，字幕保持相同偏移。首尾加停留，总片长约50.708秒。
- 混音：人声响度处理，音乐在人声出现时自动压低，保留原配音源文件。
- 语音调用脚本复用已有 Paper Theatre 研究项目的自编实现；新影片编排、音乐与排版为本任务制作。
- 没有复制账号配置或密钥到本项目。普通重新渲染不调用付费语音或图像服务。

美术提示词和源图对应关系见 `image-prompts.md`。最终生成使用内置工具，没有使用图像CLI。

## 修改与复现

在已具备 Python、Pillow、NumPy、FFmpeg、ffprobe 和对应中文字体的本机环境：

```powershell
python -B src/render_film.py --frames-only
python -B src/render_film.py --music-gain 0.70
```

仅修改配乐混音时：

```powershell
python -B src/render_film.py --mix-only --music-gain 0.70
```

字幕文稿与语音时间戳必须保持对应。改变文稿需要新的语音和时间戳；不要仅替换字幕文字冒充重新配音。

最终验证结果见 `output/qa-report.json`。
